# ⚡ Quick Start Guide

**Get started with Smart Budget v2.0 in 3 minutes!**

---

## 🎯 Step 1: Setup (30 seconds)

1. **Get API Key** (choose one):
   - [DeepSeek](https://platform.deepseek.com) - 💰 Cheapest ($0.14/M tokens)
   - [Groq](https://console.groq.com) - ⚡ Fastest (free tier)
   - [OpenAI](https://platform.openai.com) - 🏆 Best quality

2. **Open App** → Click ⚙️ Settings → Paste API Key → Save

---

## 💬 Step 2: First Commands (1 minute)

Try these in the chat:

```
Пришла зарплата 50000, до зарплаты 14 дней
```

**Result:** Balance set, daily limit calculated (~3571 ₽/day)

---

## 🏦 Step 3: Create Your First Cells (1 minute)

### Create a Deposit
```
Создай вклад 20000 рублей под 18%
```

### Create a Savings Goal
```
Копилка на отпуск цель 50000
```

### Track a Debt
```
Долг по кредитке 15000 с автовзносом 30%
```

---

## 🎉 Done! You're Ready

Now you can:
- **Track expenses:** "Купил продукты 1200"
- **Ask questions:** "На сколько дней хватит денег?"
- **Manage cells:** "Пополни копилку на 3000"
