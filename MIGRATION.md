# 🔄 Миграция с v1 на v2 (Agentic Architecture)

## 📌 Что изменилось?

### Было (v1):
```javascript
{
  currentBalance: 50000,
  creditDebt: 15000,  // ❌ Удалено
  daysSalary: 14,
  transactions: [...]
}
```

### Стало (v2):
```javascript
{
  currentBalance: 50000,
  dailyLimit: 3571,    // ✅ Добавлено (автоматически рассчитывается)
  daysSalary: 14,
  cells: [             // ✅ Добавлено (динамические ячейки)
    {
      id: 'cell_xxx',
      type: 'DEBT',
      title: 'Кредит (мигрировано)',
      amount: 15000,
      autoDeduct: 0.3
    }
  ],
  transactions: [...],
  reminders: []        // ✅ Добавлено (для будущих фич)
}
```

---

## 🚀 Автоматическая миграция

При первом запуске v2 приложение:

1. ✅ Проверяет наличие `smart_budget_data_v1` в localStorage
2. ✅ Если найдено — переносит данные в `smart_budget_data_v2`
3. ✅ Конвертирует `creditDebt` → DEBT Cell:
   - Тип: `DEBT`
   - Название: "Кредит (мигрировано)"
   - Сумма: старое значение `creditDebt`
   - Автовзнос: 30%
4. ✅ Удаляет поле `creditDebt` из нового state
5. ✅ Удаляет старый `smart_budget_data_v1` из localStorage
6. ✅ Сохраняет новую структуру

**Вы ничего не потеряете!** Все транзакции, баланс и настройки AI сохранятся.

## ❓ FAQ

### В1: Потеряю ли я историю транзакций?
**Нет.** Массив `transactions` полностью сохраняется.

### В2: Потеряю ли я API-ключ?
**Нет.** Все настройки AI (`apiKey`, `apiEndpoint`, `apiModel`) сохраняются.

### В3: Могу ли я вернуться к v1?
**Технически да**, но данные из ячеек не вернутся в старый формат. Рекомендуем перед возвратом экспортировать данные.

### В4: Что делать, если миграция сломалась?
1. Откройте DevTools (F12) → Console
2. Проверьте ошибки
3. Сообщите об ошибке в Issues на GitHub

### В5: Как удалить старые данные вручную?
Console:
```javascript
localStorage.removeItem('smart_budget_data_v1')
```
