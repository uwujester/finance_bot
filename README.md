# 💰 Smart Budget — Telegram Mini App с ИИ (Agentic Architecture)

> **Персональный финансовый ассистент нового поколения с динамическими ячейками и AI-управлением**  
> Архитектура **Zero-Backend** (чистый HTML/CSS/JavaScript), **Agentic UI** с поддержкой **DeepSeek**, **OpenRouter**, **OpenAI**, **Groq** и любых других LLM.

---

## 🌟 Ключевые особенности

### 🧠 Agentic UI — ИИ управляет интерфейсом
Революционная система взаимодействия: вы просто говорите на естественном языке, а ИИ выполняет структурированные действия:
- **Создание финансовых ячеек:** *«Создай вклад 100к под 18%»*, *«Копилка на iPhone 80000»*
- **Управление долгами:** *«Долг по кредитке 25к с автовзносом 30%»*
- **Подписки:** *«Подписка Spotify 199р списывается 5 числа»*
- **Операции с ячейками:** *«Пополни копилку на 5000»*, *«Сними 2000 с вклада»*

### 🏦 Динамические финансовые ячейки (Dynamic Cells)
Вместо жёстко заданных карточек — универсальная модульная система:
- **💰 SAVINGS** — Вклады с процентами (расчёт дохода/месяц)
- **🎯 GOAL** — Копилки на цель (прогресс-бар достижения)
- **💳 DEBT** — Долги с автовзносом при поступлении дохода
- **📅 SUBSCRIPTION** — Подписки и регулярные платежи

Каждая ячейка имеет:
- ➕ **Пополнить** — перевести средства из свободного баланса
- ➖ **Снять** — вернуть деньги на баланс
- 🗑️ **Удалить** — закрыть ячейку с возвратом средств

### 📊 Умная финансовая математика
- **Свободный баланс** = Все средства − Средства в ячейках
- **Суточный лимит** = Свободный баланс / Дней до зарплаты
- **Автоматические взносы** — при пополнении баланса ИИ может автоматически распределить % на долги

### 💬 Естественный язык для всего
- *«Пришла зарплата 50000»* → доход
- *«Купил продукты 1200 и такси 200»* → расходы
- *«До зарплаты 12 дней»* → обновление периода
- *«На сколько дней хватит?»* → финансовый совет

### 📊 Периодическая аналитика
Переключатель **День / Неделя / Месяц / Все** с автоматическим подсчётом:
- Расходы за период
- Доходы за период
- Рекомендации по долгам на основе активных ячеек

### 🔌 Универсальная поддержка LLM
- **DeepSeek** (`deepseek-chat`)
- **OpenRouter** (доступ ко всем моделям)
- **OpenAI** (`gpt-4o-mini`, `gpt-4o`)
- **Groq** (`llama-3.3-70b-versatile`)
- **Custom Endpoint** (любой OpenAI-совместимый API)

### ⚡ Zero-Backend & Полная приватность
- Работает без сервера
- Все данные только на вашем устройстве (`Telegram CloudStorage` + `localStorage`)
- API-ключ никогда не покидает устройство

### 🎨 Нативный Telegram Design
- Светлая/тёмная тема
- Haptic Feedback
- Адаптивный мобильный UI
- Интеграция профиля пользователя

## 🏗️ Архитектура

### Модульная структура кода
```javascript
// CellsManager — модуль управления ячейками
CellsManager.createCell(type, data)
CellsManager.updateCell(cellId, updates)
CellsManager.deleteCell(cellId)
CellsManager.getTotalAllocated()
CellsManager.renderCell(cell)

// Типы ячеек
CELL_TYPES = {
  DEBT: { icon: '💳', name: 'Долг / Кредит', color: '#ef4444' },
  SAVINGS: { icon: '💰', name: 'Вклад / Накопления', color: '#10b981' },
  GOAL: { icon: '🎯', name: 'Копилка на цель', color: '#8b5cf6' },
  SUBSCRIPTION: { icon: '📅', name: 'Подписка', color: '#f59e0b' }
}
```

### Agentic AI Response Format
```json
{
  "ai_response": "Дружелюбный ответ с подтверждением",
  "daily_limit": 1500,
  "actions": [
    {
      "type": "CREATE_CELL",
      "data": {
        "cellType": "SAVINGS",
        "title": "Вклад Сбер",
        "amount": 100000,
        "rate": 18
      }
    },
    {
      "type": "INCOME",
      "data": {
        "amount": 50000,
        "description": "Зарплата"
      }
    }
  ]
}
```

### Действия (Actions)
- `INCOME` — пополнение баланса
- `EXPENSE` — расход с баланса
- `CREATE_CELL` — создание новой ячейки
- `UPDATE_CELL` — изменение суммы в ячейке (пополнение/снятие)
- `DELETE_CELL` — удаление ячейки
- `UPDATE_DAYS` — изменение дней до зарплаты

## 🎯 Примеры работы с динамическими ячейками (Agentic UI)

### 📥 Создание ячеек через естественный язык

| Команда | Что создаётся |
| :--- | :--- |
| `Создай вклад 100000 рублей под 18% годовых` | 💰 **SAVINGS** — вклад с расчётом дохода/мес |
| `Копилка на iPhone 80000` | 🎯 **GOAL** — копилка с прогресс-баром |
| `Долг по кредитке Сбер 25000 с автовзносом 30%` | 💳 **DEBT** — долг (30% от дохода уходит автоматически) |
| `Подписка Яндекс Плюс 299 рублей списывается 5 числа` | 📅 **SUBSCRIPTION** — регулярный платёж |

### 💸 Операции с ячейками

| Команда | Действие |
| :--- | :--- |
| `Пополни копилку на 5000` | Перевод 5000 ₽ из свободного баланса в ячейку |
| `Сними 2000 с вклада` | Возврат 2000 ₽ на баланс |
| `Удали ячейку вклад Сбер` | Закрытие ячейки + возврат всех средств |

### 🔄 Комплексная команда (несколько действий)

**Пользователь:**
```
Пришла зарплата 60000, создай вклад 30000 под 20%, 
долг 15000 с автовзносом, до зарплаты 14 дней
```

**ИИ выполнит:**
1. ✅ INCOME: +60000 ₽ на баланс
2. ✅ CREATE_CELL (SAVINGS): -30000 ₽ → вклад под 20%
3. ✅ CREATE_CELL (DEBT): -15000 ₽ → долг с автовзносом
4. ✅ UPDATE_DAYS: 14 дней до зарплаты
5. 📊 Суточный лимит: (60000 - 30000 - 15000) / 14 = **~1071 ₽/день**

## 📊 Аналитический модуль и авто-планирование кредитки

В приложении встроен интерактивный блок финансовой аналитики:
1. **Фильтрация по таймлайну**:
   - **День** — показывает только траты и доходы за сегодняшние сутки.
   - **Неделя** — суммарная статистика за последние 7 дней.
   - **Месяц** — общая сумма расходов и поступлений за 30 дней.
   - **Все** — агрегированные показатели за всю историю операций.
2. **Умный помощник по кредитным картам**:
   - Автоматически проверяет отношение общего баланса к сумме долга и дням до зарплаты.
   - Рассчитывает оптимальный платеж: позволяет максимально быстро закрывать долг, не допуская дефицита средств на питание.

## 🛡️ Безопасность и конфиденциальность

- **Никаких сторонних серверов**: Mini App взаимодействует напрямую с выбранным вами API провайдером нейросети.
- **Локальное хранение**: API-ключ и финансовая статистика сохраняются только в вашем браузере / зашифрованном облаке `Telegram.WebApp.CloudStorage`.
- **Без передачи третьим лицам**: Ваш баланс и история трат не отправляются ни на какие аналитические сервера.
